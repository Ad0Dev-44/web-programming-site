History of the Web

From a proposal at CERN in 1989 to the interactive platform we use today, the World Wide Web has transformed how information is created, shared, and accessed.

A Brief History of the World Wide Web

Watch this short overview from CERN explaining the origins and early development of the World Wide Web.

Timeline

1989 — World Wide Web Proposed

Tim Berners-Lee proposed a system for sharing information through hypertext while working at CERN. His proposal became the foundation of what would later become the World Wide Web.

Source: CERN

December 20, 1990 — First Website and Web Server Live

By the end of 1990, Tim Berners-Lee had created the first Web server and Web browser at CERN. The first Web server ran on a NeXT computer in his office.

Source: CERN

August 6, 1991 — Web Opened to the Public

The World Wide Web software was released to the wider Internet community. The project was also announced on Internet newsgroups, allowing researchers outside CERN to begin using and developing the Web.

Source: W3C

April 30, 1993 — CERN Releases Web Software Publicly

On April 30, CERN released the World Wide Web software into the public domain. This allowed anyone to use and develop the technology freely, helping accelerate the growth of the Web.

Source: W3C

1993 — Mosaic Brings Images to the Browser

NCSA's Mosaic browser was among the first to display images inline with text rather than in separate windows, giving the Web a magazine-like look that helped it reach a mainstream, non-technical audience.

Source: Living Internet

October 1994 — Netscape Navigator Released

Netscape Communications released Navigator, which quickly became the dominant browser of the mid-1990s and helped ignite the "browser wars" that shaped early Web standards.

Source: Encyclopaedia Britannica

October 1, 1994 — World Wide Web Consortium (W3C) Founded

Tim Berners-Lee founded the World Wide Web Consortium (W3C) to coordinate the development of Web standards and keep the Web open and interoperable.

Source: W3C

1995 — JavaScript Introduced

Netscape engineer Brendan Eich created JavaScript, adding interactivity to otherwise static web pages and laying the groundwork for the dynamic, application-like websites of later decades.

Source: W3C

December 1996 — CSS Published

The W3C published the first Cascading Style Sheets (CSS) recommendation, separating a page's visual presentation from its underlying HTML structure and making consistent, reusable web design possible.

Source: W3C

1998 — Google Search Launches

Google's PageRank-based search engine made the rapidly growing Web far easier to navigate, quickly becoming most people's primary entry point to online information.

Source: Google

2004 — "Web 2.0" and Social Platforms Emerge

The term "Web 2.0" spread to describe a more interactive, user-generated Web, exemplified by the founding of Facebook (2004) and the launch of YouTube (2005), which turned users from readers into publishers.

Source: Encyclopaedia Britannica

Jan 9, 2007 — iPhone Unveiled

Apple introduced the first iPhone, combining a mobile phone with Internet access, a Web browser, and other computing capabilities. The device helped accelerate the shift toward accessing the Web through mobile devices.

Source: Apple

2008 — Google Chrome Released

Google launched the Chrome browser, whose fast JavaScript engine and rapid update cycle pushed the whole industry toward faster, more standards-compliant browsers and richer in-browser applications.

Source: Google

2014 — HTML5 Finalized

The W3C finalized the HTML5 standard, adding native support for audio, video, graphics, and offline storage without third-party plugins, and enabling the responsive, app-like websites common today.

Source: W3C

2015 — HTTP/2 and the Mobile-First Web

HTTP/2 was standardized to speed up page loading, while mobile traffic overtook desktop traffic worldwide, pushing designers toward mobile-first and responsive Web design as the default approach.

Source: W3C

2015–2017 — Progressive Web Apps and WebAssembly

Google introduced Progressive Web Apps, letting websites behave like installable native apps, while WebAssembly (2017) let browsers run near-native-speed code, expanding what could be built directly on the Web platform.

Source: WebAssembly.org

2018 — GDPR and a Renewed Focus on Web Privacy

The European Union's General Data Protection Regulation took effect, forcing websites worldwide to rethink how they collect, store, and disclose the use of personal data, reshaping cookie consent and privacy design across the Web.

Source: GDPR.eu

2020 — The Web Becomes Essential Infrastructure

The COVID-19 pandemic pushed schooling, work, healthcare, and social life onto the Web almost overnight, driving a surge in video conferencing, e-commerce, and cloud-based collaboration tools.

Source: International Telecommunication Union (ITU)

November 30, 2022 — Generative AI Enters the Browser

The public launch of OpenAI's ChatGPT popularized generative AI, which browsers, search engines, and websites quickly began embedding directly into the everyday Web experience.

Source: OpenAI

2023–2026 — AI Agents and the Next Web

AI assistants gained the ability to browse, click, and fill out forms on a person's behalf, while questions around AI-generated content, digital identity, and platform regulation continue to shape how the Web is built and governed today.

Source: W3C

Key Web Technologies and Standards

Technology / Standard Introduced Purpose
HTML 1990–1991 Markup language used to structure web page content
HTTP 1990–1991 Protocol used to request and transfer web pages
JavaScript 1995 Scripting language that adds interactivity to web pages
CSS 1996 Language for styling and laying out web pages
XMLHttpRequest / AJAX 1999–2005 Enabled pages to update content without a full reload
HTML5 2014 Added native audio, video, graphics, and offline support
HTTP/2 & HTTP/3 2015 / 2022 Faster, more efficient transport for modern websites
Progressive Web Apps 2015 Let websites be installed and behave like native apps
WebAssembly 2017 Runs near-native-speed compiled code inside the browser
